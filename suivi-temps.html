📖 Configurer Google Drive
Étape 1 — Créer un projet Google Cloud
Allez sur console.cloud.google.com → Nouveau projet → donnez-lui un nom (ex: "Chrono Travail").
Étape 2 — Activer Google Drive API
Menu → APIs et services → Bibliothèque → cherchez "Google Drive API" → Activer.
Étape 3 — Écran de consentement OAuth
APIs et services → Écran de consentement OAuth → Externe → remplissez le nom de l'app → Enregistrer.
Étape 4 — Créer les identifiants
APIs et services → Identifiants → Créer des identifiants → ID client OAuth → Application Web → ajoutez l'URL affichée dans "Origine autorisée" → Créer. Copiez le Client ID.
Étape 5 — Héberger l'application
Si vous ouvrez le fichier en local (file://), Google refusera la connexion. Il faut héberger le fichier sur un serveur HTTPS. La solution gratuite la plus simple :

1. Créez un compte sur github.com
2. Nouveau dépôt public → uploadez ce fichier HTML
3. Settings → Pages → Source: main → Save
4. Votre URL sera : https://votrepseudo.github.io/votre-repo/suivi-temps.html
5. Ajoutez cette URL comme "Origine autorisée" dans Google Cloud Console
